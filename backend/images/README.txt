=========================================================
CARPETA DE IMÁGENES PARA EL CARRUSEL MEDCONNECT
=========================================================

Puedes colocar aquí tus archivos de imagen para el carrusel de la página principal.

Nombres de archivo configurados en index.html:
- images/slide1.jpg (o .png / .webp)
- images/slide2.jpg (o .png / .webp)
- images/slide3.jpg (o .png / .webp)
- images/slide4.jpg (o .png / .webp)

Dimensiones recomendadas:
- Proporción aproximada: 16:9 o 16:10 (ej. 1200x675px o 1400x800px)
- Formatos admitidos: JPG, PNG, WEBP, SVG

Una vez que guardes tus imágenes aquí, se visualizarán automáticamente en el carrusel de index.html.
