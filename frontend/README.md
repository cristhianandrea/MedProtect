# 🌐 Portal Médico

Portal web interactivo para pacientes, médicos, tutores y personal clínico de la plataforma **MedConnect**.

---

## 🚀 Cómo Ejecutar el Proyecto

Para ejecutar el frontend, abre el archivo `index.html` en el navegador o mediante una extensión de servidor local (ej. Live Server).

---

## 📂 Archivos del Frontend

- `index.html` - Página principal de acceso, registro y portal multi-rol.
- `paciente-dashboard.html` - Dashboard del paciente (agenda, citas, recetas y expediente).
- `styles.css` - Hoja de estilos y diseño clínico.
- `script.js` - Lógica de interacción, validación y control de interfaz.
- `api-client.js` - Conector HTTP para sincronización con la API REST.
